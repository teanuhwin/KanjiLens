About

漢字レンズ translates kanji from photos into hiragana and romaji — fully offline after the first load.

Capture or upload a photo, correct any OCR errors, then tap Convert. Results are saved locally.

Camera & File Access

HTTPS required for camera. GitHub Pages provides HTTPS automatically — camera will work once deployed.

On iOS: allow camera when prompted by Safari. On Android: tap Allow when Chrome asks. If previously denied, go to browser Settings → Site Settings → Camera to re-enable.

File upload (photo library) works on both platforms without special permissions and does not require HTTPS.

How It Works

All processing is local — no data is ever sent to a server.

Tesseract.jsOCR — reads kanji from images
kuromoji.jsMorphological analysis — kanji → kana
wanakana.jsKana → romaji conversion
Service WorkerCaches all assets for offline use
Tips for Better OCR

• Good lighting and a flat, non-glare surface improve accuracy significantly.

• Printed text (menus, signs, books) works best. Handwriting is less reliable.

• If confidence is low, edit the detected text before converting.

• Crop tightly around the text for best results.
